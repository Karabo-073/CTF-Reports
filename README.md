**13 Professional Security Research Reports. Multiple Attack Surfaces. One Research Discipline.**

Welcome to my Capture The Flag (CTF) research archive. This repository documents 13 technical security investigations conducted across multiple cybersecurity platforms, including **BugForge and TryHackMe (THM)**.

This collection demonstrates practical security research, vulnerability investigation, exploitation methodology, operating system analysis, and systematic problem-solving across diverse technical environments.

The objective is not simply to capture flags, but to understand how vulnerabilities emerge, how systems can be compromised, how attack paths develop, and how security weaknesses can be identified and addressed.

## RESEARCH METHODOLOGY

My approach to CTF investigations focuses on understanding the underlying technology rather than blindly executing tools.

**01 — Reconnaissance**

Identify exposed services, technologies, entry points and potential attack surfaces.

**02 — Enumeration**

Investigate system behaviour, application functionality, configurations and accessible resources.

**03 — Vulnerability Analysis**

Identify security weaknesses and understand their underlying causes.

**04 — Exploitation**

Validate vulnerabilities through controlled exploitation within authorised CTF environments.

**05 — Post-Exploitation**

Investigate the resulting access, privilege boundaries and available attack paths.

**06 — Documentation**

Produce structured technical reports containing reproducible methodologies, evidence and remediation recommendations.
